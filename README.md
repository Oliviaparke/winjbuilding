# WIN-J BUILDING SOLUTION — Portfolio Website

A modern architectural and construction portfolio website custom-tailored for **WIN-J BUILDING SOLUTION**, incorporating 30 years of industry experience and 70+ completed residential projects across South India. Fully responsive across PCs, laptops, tablets, and mobile smartphones.

## 🌟 Live Preview & How to Run
Simply open `index.html` in your web browser:
- Double-click `index.html` in `c:\Users\USER\Downloads\win-j-building-solution\`
- Or right-click `index.html` → **Open with** → **Google Chrome** / **Microsoft Edge**

---

## 📱 Device Compatibility & Responsive Breakpoints
The layout is optimized for all device viewports:
- **Desktop & PC (> 1200px):** Full luxury editorial layout with 3-column philosophy section, floating project previews, and multi-column portfolio grids.
- **Tablets & Small Laptops (768px – 1024px):** Balanced stacking with center philosophy statements leading into image previews, 2-column project grids, and clean touch navigation.
- **Mobile Phones (320px – 768px):** 
  - Zero horizontal overflow with fluid `clamp()` typography.
  - Smooth slide-out mobile drawer menu.
  - Touch-friendly buttons (minimum 46px tap target).
  - Form fields set to 16px font-size to prevent iOS Safari auto-zoom.
  - Responsive single-column modal lightbox.
  - Floating WhatsApp quick-chat button accessible from anywhere on the page.
